# Food Calorie Predictor

## Project Overview

Food Calorie Predictor is a Python-based application that estimates the calorie content of a selected food item based on the quantity entered by the user.

The application provides a graphical user interface using Tkinter and uses food calorie data stored in a CSV file.

## Features

- Select a food item from a dropdown list.
- Enter the quantity of food in grams.
- Calculate the estimated calorie content.
- Display the calorie prediction in kcal.
- Display the calculation formula.
- Maintain a history of recent predictions.
- Visualize prediction results using charts.

## Technologies Used

- Python
- Tkinter
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
